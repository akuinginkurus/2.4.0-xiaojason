Wall-E Prambors radio-only source update

Implemented in this source package:
- AudioService radio PCM queue; AudioOutputTask remains the only I2S output task.
- HTTPS stream reader for the Prambors Revma stream URL.
- AAC/MP3 selection based on HTTP Content-Type and Espressif Simple Decoder.
- Stereo-to-mono downmix and resampling to 24 kHz.
- MCP tools: self.radio.play_prambors and self.radio.stop.
- GPIO0 short click requests radio stop; long press Wi-Fi configuration is unchanged.
- Wake-word / voice-processing state is restored after radio playback ends.

IMPORTANT:
This source package has NOT been built with ESP-IDF in this environment because
idf.py / IDF_PATH are unavailable here. It is not certified ready to flash.
The first ESP-IDF build should be run for target esp32c3 and board pocket-wall-e-c3.
